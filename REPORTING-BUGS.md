# Reporting localization bugs

Thank you for helping improve **The Matchless Kung Fu — English Overhaul**.

GitHub Issues are the preferred place for reports:

https://github.com/kijuyi/Matchless-English-Overhaul/issues/new/choose

## A useful report contains

1. **Screenshot** showing the problem.
2. **Exact English text** visible on screen, if readable.
3. **What you were doing** — quest, event, panel, interaction, combat, etc.
4. **Location/system** — for example Sect Council, The Wilds, Meridian screen, Enlightenment Stone, NPC conversation.
5. **The previous choice/action**, if the problem appeared after selecting something.
6. Optional: what you think is wrong or what you expected it to mean.

## Especially useful reports

Please report things such as:

- dialogue that still reads like machine translation or makes little sense
- wrong speaker, pronoun, subject, or object
- a response that does not logically follow the previous line
- missing information compared with what gameplay actually does
- incorrect numbers, costs, durations, percentages, or effects
- untranslated Chinese
- text clipping or overflow
- literal placeholders such as `{0}`, `{1}`, etc.
- inconsistent names for the same martial art, faction, item, location, or mechanic
- a choice whose result does not match what the choice says
- a system label that appears to belong to another reused UI panel

## Before reporting

Please mention that you are using **English Overhaul v1.0.1**.

If possible, reproduce the problem with other English-translation mods disabled. Mods that replace the same localization or UI assets can conflict.

## Advanced or unusual systems

Reports from **The Wilds**, advanced **Sect** systems, unusual event chains, and rare NPC interactions are particularly valuable because those surfaces are harder to exhaustively reproduce during development.

## What happens after a report?

The v1.0.1 release is frozen.

Confirmed corrections will be collected and released in a new version such as **v1.0.2** rather than silently changing the existing v1.0 package.
