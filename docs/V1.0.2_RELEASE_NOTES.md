# The Matchless Kung Fu — English Overhaul v1.0.2

> **GitHub release ·2026-10-28.** Steam Workshop is a separate delivery channel and is not updated by this GitHub publication.

## What changed

This is an editorial and runtime localization maintenance update built on the existing overhaul, not a new translation or a replacement for the game's mechanics.

- Refined owner-reviewed English event dialogue, including sect onboarding wording, character voice and contextual consistency.
- Corrected the generic `Roamer` identity label in its appropriate context; narrative uses of `Refugee` are separate.
- Consolidated canonical mastery-stage language, including **Adept** rather than the incorrect **Veteran** in affected contexts.
- Improved item descriptions to avoid empty delimiters when optional character identifiers are absent. Visual verification includes `CheSanxiao's Head` and other head-item names.
- Preserved prior approved UI, equipment, localization and runtime fixes rather than discarding them during release integration.

The private integration report for the selected candidate records 58 owner-approved editorial cells (including eight earlier Event7020 cells), 85 C051 entries, 54 SkillEntry changes and 158 mounted runtime overrides. These figures count reviewed/integrated rows, not 158 individually visually tested features.

## Verification and limitations

- Private release QA reported successful production bootstrap and loaded-world tests, with the 158 runtime text entries mounted and no internal auditor included.
- Visual owner screenshots show **Golden Bell Shield · Adept** in the martial-insight comparison UI (not a blanket proof of all Event466/7125 dialogue paths).
- Visual owner screenshots show the corrected empty-identifier head item text, including the description of CheSanxiao; non-empty identifier variants remain supported by offline tests, not claimed visually confirmed here.
- This is **not** a claim of complete visual coverage of the sandbox. In particular, some advanced systems and rare event paths remain less exercised.

## Known issue and excluded experiment

- [Issue #2 — Martial-insight card heading concatenation](https://github.com/kijuyi/Matchless-English-Overhaul/issues/2): some cards show `AdvanceAdept`, `AdvanceProficient`, `AdvancePerfected`, `AdvanceTranscendent`, or `AdvanceNovice` without a natural separator. Minor visual defect; postponed for a later patch. It does **not** mean the rank `Adept` itself is untranslated.
- The independent experimental **Split Name&Surname 2.0** integration did not pass its NPC visual gate and is **not included in v1.0.2**. The previously approved event-created-NPC name correction is a separate, narrower fix.

## Installing or rolling back

**Use the [v1.0.2 installation instructions](../README.md#installation--v102-steam-windows-or-linuxproton), not the PAK-only instructions from v1.0.1.** Install all three files together into the existing subscribed carrier's Workshop cache directory `steamapps/workshop/content/1696440/3808208955/`, with game/Proton closed and backups made. The game rebuilds its local mod copy from that cache on startup. Copying only the PAK or editing only the game-managed copy does not install the complete update.

The ZIP has no Linux install/uninstall scripts. Windows and Linux/Proton use the same Steam carrier directory structure; see README for the exact steps, legacy standalone PAK cleanup and hash commands. Restore the three original backup files with game/Proton closed to roll back; never migrate or restore saves as part of mod rollback.

Game source/compatibility target: **1.4.0.7**. Production startup/world QA was performed in an isolated Linux/Proton environment. This is not independent Windows playtest certification, fresh no-BET native certification or complete visual coverage of every event/optional identifier variant.
